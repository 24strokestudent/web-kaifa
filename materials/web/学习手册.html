知识点 01

浏览器、HTML 文件与网页的关系

浏览器不是直接执行 HTML 里的中文说明，而是解析标签，建立 DOM 树，然后把内容绘制到屏幕。双击 index.html 使用 file:// 打开；日后接入接口时通常改用本地开发服务器（http://localhost）。

知识点 02

doctype、head、body、title、charset

<!DOCTYPE html> 声明按现代 HTML 标准解析；html 包含整份文档；head 保存元数据，body 保存页面内容。meta charset="UTF-8" 避免乱码；viewport 让手机按设备宽度布局。

知识点 03

标题 h1/h2、段落 p、基本标签嵌套

h1 是页面最高层级标题，h2 用于大板块，p 用于一段完整的话。标题不是用来随便放大字体的：应保持合理层级并成对闭合标签。

index.htmlHTML
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>算法社团｜首页</title>
</head>
<body>
  <h1>算法社团</h1>
  <p>我们一起学习算法、参加比赛。</p>
  <h2>关于我们</h2>
  <p>每周组织一次训练。</p>
  <h2>近期活动</h2>
  <p>本周六：基础图论交流。</p>
</body>
</html>

今天按这几步操作

  1. 创建 web-study 文件夹，并用 VS Code 打开。
  2. 新建 index.html，输入示例并保存为 UTF-8。
  3. 双击打开网页，修改 h1 后刷新，观察变化。
  4. 把 title 改为“我的社团网站”，看浏览器标签页变化；最后新增“联系我们”板块。
自测：为什么修改 <title> 不会把网页正文里的大标题一起修改？ · 点击看参考解释

title 是 head 中的文档元信息，通常用于浏览器标签页；正文标题属于 body 中的 h1，两者是不同的元素。

排错提示：看见源代码而不是页面？检查扩展名是否真为 .html、是否在浏览器里打开。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

a href 的地址、锚点与相对路径

a 是可以导航的链接。href="https://..." 指向网址；href="about.html" 指向同目录文件；href="#events" 跳到当前页面 id="events" 的位置。路径是相对于当前 HTML 文件计算的。

知识点 02

img src/alt 的含义

img 用 src 告诉浏览器去哪找文件，用 alt 描述图片信息。图片加载失败时 alt 有帮助，使用读屏器的人也会读到它；纯装饰图可用 alt=""，但有意义的图片不要留空。

知识点 03

header/nav/main/section/footer 的使用

header 表示页眉，nav 是主要导航，main 是主要内容，section 是主题板块，footer 是页脚。这些标签有语义，不是浏览器自动帮你做好外观。

index.html（插入到 body）HTML
<header>
  <h1>算法社团</h1>
  <nav aria-label="页面导航">
    <a href="#about">关于我们</a>
    <a href="#events">近期活动</a>
  </nav>
</header>
<main>
  <section id="about"><h2>关于我们</h2><p>欢迎参加训练。</p></section>
  <section id="events">
    <h2>近期活动</h2>
    <img src="images/training.jpg" alt="社团成员在机房讨论算法题" width="420">
  </section>
</main>
<footer><p>2026 算法社团</p></footer>

今天按这几步操作

  1. 在 web-study 内创建 images 文件夹，放一张你有使用权的照片并命名 training.jpg。
  2. 将 h1 和导航放入 header，把主要板块放到 main。
  3. 给两个 section 各设置唯一 id，测试导航的锚点跳转。
  4. 故意把 src 改错，再打开开发者工具 Console/Network 查看失败的图片请求。
自测：index.html 位于网站根目录，照片位于 images/a.png，src 应怎样写？ · 点击看参考解释

写成 src="images/a.png"（或 ./images/a.png）。图片路径相对于 index.html 所在目录。

排错提示：不要把本地绝对路径 C:\Users\... 写入网页：别人电脑上没有这条路径。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

link 引入 style.css

HTML 决定“是什么”，CSS 决定“长什么样”。用 <link rel="stylesheet" href="style.css"> 在 head 中连接样式文件；同目录才能直接这样写。

知识点 02

标签、类、伪类选择器

h1 匹配所有一级标题；.card 匹配 class="card" 的元素；.card:hover 只匹配悬停状态。优先使用 class 写组件外观，少用过长的选择器链。

知识点 03

颜色、字体、行高、背景、继承

color 修改文字色，background-color 修改背景；font-size 是字号、line-height 是行高。子元素可能继承字体属性，但一般不会继承 padding 或 border。

style.cssCSS
/* index.html 的 head 加：<link rel="stylesheet" href="style.css"> */
body { font-family: Arial, sans-serif; background: #f6f8f8; color: #263238; }
h1 { color: #136b59; }
section { background: white; padding: 16px; margin: 16px 0; }
section p { line-height: 1.8; }
.highlight { color: #b34333; font-weight: bold; }

自测：只希望“近期活动”板块有蓝色标题，应该修改所有 h2 还是给该标题加类？ · 点击看参考解释

优先给这个标题一个单独的 class，再写 .类名 选择器；修改所有 h2 会影响其他板块。

排错提示：选择器写 .card 时，HTML 应是 class="card"，不是 id="card"。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

margin / padding / border / content

浏览器里的每个元素都占据一个矩形盒子：内容 content → 内边距 padding → 边框 border → 外边距 margin。padding 在盒子内；margin 在盒子外，不属于背景区域。

知识点 02

width 与 box-sizing:border-box

默认 content-box 的 width 只算内容宽度，padding/border 会额外增加总宽；box-sizing:border-box 会把 padding/border 纳入已设置的 width，更易控制布局。

知识点 03

块级元素和行内元素的差别

div、section 默认通常独占一行；span、a 是常见行内元素，通常随文字排列。display 属性可以改变表现，但语义由标签本身决定。

style.cssCSS
* { box-sizing: border-box; }
.card {
  width: 300px;
  padding: 20px;
  border: 1px solid #d9e1e0;
  margin: 16px 0;
  background: white;
  border-radius: 12px;
}
.card h3 { margin-top: 0; }

今天按这几步操作

  1. 在 HTML 新增 <article class="card">，包含标题、时间和说明。
  2. 按代码设置宽 300px、padding 20px、border 1px。
  3. 在浏览器 DevTools 的 Computed → Box Model 查看各层数值。
  4. 暂时删掉 box-sizing，比较卡片总宽是 300px 还是 342px，再恢复。
自测：width:300px；左右 padding 各 20px；左右 border 各 1px，默认 content-box 的总宽是多少？ · 点击看参考解释

342px：300 + 20×2 + 1×2。设置 border-box 后，总宽变为 300px。

排错提示：margin 的垂直折叠会造成距离“不按加法计算”；先检查实际盒模型，不要盲目调大数字。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

display:flex 与主轴/交叉轴

Flexbox 负责单维排列：一排或一列。给父元素 display:flex，子元素自动参与 Flex 布局；默认主轴水平向右（direction:row），修改方向后主轴也会改变。

知识点 02

justify-content、align-items、gap

justify-content 控制主轴方向的排列，align-items 控制交叉轴方向的对齐。flex-direction:column 时，justify-content 不再是“水平对齐”。

知识点 03

flex-wrap、flex-grow 基本含义

gap 是项目之间的间隔；flex-wrap:wrap 允许空间不足时换行；flex:1 常用来让某个区域占据剩余空间，不等于写死宽度。

style.cssCSS
* { box-sizing: border-box; }
.topbar { display: flex; align-items: center; gap: 20px; }
.topbar nav { margin-left: auto; display: flex; gap: 14px; flex-wrap: wrap; }
.topbar a { color: #136b59; text-decoration: none; }
@media (max-width: 600px) {
  .topbar { align-items: flex-start; flex-direction: column; }
  .topbar nav { margin-left: 0; }
}

今天按这几步操作

  1. 给 header 加 class="topbar"，其中放社团名称与 nav。
  2. 写 display:flex 和 gap，观察导航如何排列。
  3. 把 flex-direction 改成 column，验证两个对齐属性的作用。
  4. 缩窄窗口，看链接何时拥挤；再试 flex-wrap 和示例里的媒体查询。
自测：当 flex-direction:column 时，justify-content 控制水平还是垂直方向？ · 点击看参考解释

主轴改为纵向，所以 justify-content 控制纵向分布；align-items 控制横向对齐。

排错提示：给单个元素 text-align:center 不能取代父元素 Flexbox 对多个子元素的布局。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

类名复用与组合

同类卡片共享 .card 样式，内容可以不同。CSS 的复用原则是“同样的结构同样的类”，不要为三张卡片各复制一次相同声明。

知识点 02

卡片图片 object-fit 和圆角

object-fit:cover 可以让图片填充固定比例的区域并裁剪边缘；它不会改变图片原文件的内容。对内容重要的图片，裁剪前注意不要截掉关键信息。

知识点 03

按钮/链接 hover 与 focus 状态

鼠标可看到 :hover，但键盘用户通常依赖 :focus-visible。链接用 a，提交或动作使用 button；具有功能的元素不应该伪装成普通 div。

style.cssCSS
.cards { display: flex; gap: 16px; flex-wrap: wrap; }
.card { flex: 1 1 230px; border: 1px solid #ddd; border-radius: 12px; overflow: hidden; }
.card img { width: 100%; aspect-ratio: 16/9; object-fit: cover; }
.card-content { padding: 16px; }
.card a { color: #136b59; }
.card a:hover { text-decoration: underline; }
.card a:focus-visible { outline: 3px solid #ffb347; outline-offset: 4px; }

今天按这几步操作

  1. 用同一个 .card 结构写三张不同内容的活动卡片。
  2. 给卡片容器加 .cards 类，使用 Flexbox 排列。
  3. 给每张图片设置 16:9 的展示比例，观察是否拉伸。
  4. 不断按 Tab，在三个活动链接之间移动，确认焦点清晰可见。
自测：应该把打开“活动详情页”的元素写成 a 还是 button？ · 点击看参考解释

导航到另一个页面或 URL 应用 <a href="...">；触发当前页动作才主要用 <button>。

排错提示：不要只写 :hover 忘了键盘焦点；也不要把可点击卡片实现为没有键盘支持的 div。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

display:grid 与 grid-template-columns

Grid 是二维布局：同时安排列和行。display:grid 给父容器建立网格，grid-template-columns 定义列宽，gap 定义格子间距。

知识点 02

repeat/minmax/gap

repeat(3,1fr) 代表三列均分；minmax(最小,最大) 控制列宽区间，auto-fit 能在容器变窄时减少列数。

知识点 03

Grid 与 Flex 的使用边界

导航通常按一维排布适合 Flexbox；活动卡片横纵都有规则，Grid 更直观。两者不是“谁更高级”，而是适用场景不同。

style.cssCSS
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
  gap: 20px;
}
.card { min-width: 0; padding: 20px; background: white; border: 1px solid #ddd; }
.card h3 { overflow-wrap: anywhere; }

今天按这几步操作

  1. 将 Day 6 的活动容器从 flex 改为 grid。
  2. 添加第四、第五张活动卡片，不修改列数。
  3. 把浏览器从 1440px 拖到 375px，观察每行卡片个数变化。
  4. 尝试改成 repeat(3,1fr)，观察窄屏如何挤压，再改回自适应。
自测：Grid 的 1fr 是固定 1 像素吗？ · 点击看参考解释

不是。fr 表示网格容器里可分配空间的份额，多个 1fr 列通常等比例分配剩余空间。

排错提示：固定三列的 Grid 在手机上可能会拥挤；根据内容宽度调整列数。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

viewport、相对尺寸、max-width

响应式目标是让内容在不同宽度都可读。viewport 元信息让移动浏览器正确按设备宽度计算布局；max-width 防止大屏内容无限拉宽。

知识点 02

@media 的基础语法

@media (max-width: 640px) 表示视口宽度不超过 640px 时生效；断点依据内容什么时候出现拥挤选取，而不是死记手机型号。

知识点 03

内容驱动的断点设计

常用相对单位有 %、rem、vw。宽度建议用 width:100% 配合 max-width；小屏要考虑外边距、图片宽度与长单词。

style.cssCSS
body { margin: 0; }
.container { width: min(100% - 32px, 1080px); margin-inline: auto; }
.intro { display: grid; grid-template-columns: 2fr 1fr; gap: 28px; }
img { max-width: 100%; height: auto; }
@media (max-width: 680px) {
  .intro { grid-template-columns: 1fr; }
}

今天按这几步操作

  1. 把页面内容放进 class="container" 的容器。
  2. 大屏为简介区域设置 2:1 两列；窄屏改为单列。
  3. 使用 DevTools 设备模拟分别检查 360px、768px、1440px。
  4. 找到第一次出现重叠或横向滚动的宽度，说明你选断点的理由。
自测：响应式是不是给每种手机型号写一个 @media？ · 点击看参考解释

不是。按页面内容的承载能力选择少量必要断点，配合弹性宽度和自适应布局，避免为机型逐一硬编码。

排错提示：不要为隐藏错误而给 body 随手加 overflow-x:hidden；先定位超宽元素。

展开今日知识讲义 · 讲解 / 代码 / 作业 / 自测约 20–35 分钟阅读
知识点 01

form、label、input、button 结构

form 表示一个表单；label 让字段有可识别的名称。label 的 for 值要与 input 的 id 一致。button 默认在 form 内常会触发表单提交。

知识点 02

required、placeholder 与 label 区别

placeholder 是输入提示，不等于 label：用户输入后 placeholder 往往消失。required 可以让浏览器进行基础必填检查，但不能替代服务端校验。

知识点 03

键盘焦点、disabled 状态与 alt

必须能用键盘操作表单：Tab 切换焦点，focus-visible 保留清晰提示。若表单没有后端，不能在点击后显示“已经收到你的报名”。

index.html（表单片段）HTML
<form action="#" method="get">
  <label for="student-name">姓名</label>
  <input id="student-name" name="name" type="text" required>
  <label for="message">想交流的内容</label>
  <textarea id="message" name="message" rows="3" required></textarea>
  <button type="submit">检查表单字段</button>
</form>

const app = express();

const events = [{id:1,title:'图论训练'}];
app.get('/api/events', (req,res) => res.json(events));
app.post('/api/events', (req,res) => {

  events.push(item);
  res.status(201).json(item);
});
app.listen(3000);
