# 学习进度与备份

[Web 进度](web.md) 和 [Go 进度](go.md) 是随 Git 同步的学习记录。初始均未勾选，完成实际练习并通过验收后再更新。

## 浏览器手册的进度

两份互动手册将勾选记录保存到浏览器本地存储。更换浏览器、移动文件、清理浏览器数据后，原记录可能不显示。Git 提交 HTML 不会自动提交浏览器存储。

- **Web**：点击手册中的“导出勾选进度”，得到 Markdown。建议保存为 `backups/web/YYYY-MM-DD.md`；可按导出内容更新 `web.md`。当前 Web 手册没有进度导入入口，导出主要用于记录和备份。
- **Go**：点击“导出进度”，得到 JSON。建议保存为 `backups/go/YYYY-MM-DD.json`；以后用 Go 手册的导入入口恢复。导入会替换该浏览器当前记录，请先备份当前进度。

`backups` 子目录在第一次导出时创建。同一天多次备份可加时间后缀，保留需要的历史记录。
