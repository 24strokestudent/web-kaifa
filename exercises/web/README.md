# Web 小练习

从 `day01-html` 等实际练习目录开始，保存自己写的 HTML、CSS、JavaScript 和简短 README。README 写明打开或启动方式、完成的功能、验收结果和仍未解决的问题。

课程任务见 [Web 学习路线](../../materials/web/学习路线.md)。可以独立运行、包含多阶段功能的作品整理到 `projects/web`。

现有可运行的参考起点：

- [活动搜索](activity-filter/README.md)：数组筛选、DOM、数量与空结果；分类与重置留作练习。
- [请求状态](request-states/README.md)：真实本地请求，验证成功、空数据、404 与坏 JSON；需本地 HTTP 服务。

网站的“练习工坊”还有语义 HTML、盒模型、布局、表单、纯函数和 Web + Go 联调任务。运行参考例子不表示课时完成，要留下自己的实现与验收证据。
