# 活动搜索：数据、事件与渲染

这是**可运行的参考起点**，已经实现关键词搜索、数量提示和空结果。分类筛选、清空、URL 同步还没有实现，留作练习。它不代表你已经完成课时。

对应网站：`#/exercise/web-filter`。前置知识：JavaScript 数组、函数、DOM 与事件。

## 启动

直接双击本目录 `index.html`。也可以从仓库根目录执行：

```powershell
python -m http.server 8743
```

访问 `http://localhost:8743/exercises/web/activity-filter/`。不需要 npm 或外部网络。

## 先看懂，再自己改

1. 看 `activities` 的数据结构，以及 `filterActivities` 如何返回新数组。
2. 看 `render` 怎样从同一份筛选结果更新列表、数量和空结果。
3. 增加“全部 / Web / Go”分类控件，让分类与关键词同时生效。
4. 增加清空按钮，同时恢复输入、分类、列表和数量。

加练：用 URLSearchParams 保存筛选，使刷新、分享和浏览器返回可以还原条件。

## 验证

| 操作 | 当前起点的预期 |
| --- | --- |
| 首次打开 | 3 场活动 |
| 输入 `  go  ` | 1 场 Go 活动；忽略大小写与前后空格 |
| 输入 `火星` | 0 场，出现空结果文字 |
| 输入 `<b>` | 按普通文字搜索，不执行 HTML |
| 清空文本 | 恢复 3 场 |

完成分类后再验证：关键词与分类交集正确；切换分类后数量等于实际可见条数；清空按钮恢复全部。用键盘操作控件，并在 320px 宽度检查页面。

## 已知限制

只有本地演示数据，没有报名、账号、接口或持久化。关键词匹配仅检查标题。参考起点用 textContent 展示数据，不把用户输入当 HTML 解析。分类和 URL 同步是待做任务。
