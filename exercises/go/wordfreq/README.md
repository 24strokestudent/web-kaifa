# 词频统计：map、slice 与确定排序

这是**完整可运行的参考例子**，包含计数与基础测试。请先预测输出、运行核对、再合上参考独立写一遍。TopN、标点清洗和新的边界用例还没有实现，留作练习。运行例子不代表课程已完成。

对应网站：`#/exercise/go-wordfreq`，对应 Go 第 3 / 6 课。没有 C++ 前置要求。

## 启动与验证

需要 Go 1.22 或更高版本。这个目录已有自己的 go.mod，无第三方依赖。

```powershell
cd exercises/go/wordfreq
go run .
go run . "b a"
go run . "Go go WEB"
go test ./...
go vet ./...
```

从仓库根目录执行上述 cd。默认运行输出：

```text
go:2
web:1
```

`b a` 应输出 `a:1`、`b:1`，因为次数并列时按词典序排序。空输入没有输出。测试检查空白、大小写、并列顺序、含中文的空白分隔词和标点保留规则。

## 独立练习

1. 用自己的话解释：为什么先使用 map，再转成切片？为什么不能依赖 map 的遍历顺序？
2. 新增 TopN，并明确 n=0、n 超过词数、n<0 的行为。
3. 为 TopN 写测试，确认它不会意外改变调用者传入的切片。

加练：先写清标点处理的输入输出，再实现清洗。改变规则时同步修改文档与测试。

## 已知限制

以 Unicode 空白分词，使用 strings.ToLower 归一化大小写，标点仍保留。不做中文自然语言分词、词形还原或 Unicode 归一化；字符串排序不是语言学意义上的字典排序。只处理命令行传入或默认的短文本，无文件读取与服务端接口。
